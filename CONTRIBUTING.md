# CONTRIBUTING

## Loop

DISCOVER → DEFINE → DESIGN → IMPLEMENT → VERIFY → EVIDENCE → DOCUMENT → REVIEW → INTEGRATE → REASSESS

## PR standard

Use `.github/PULL_REQUEST_TEMPLATE.md`. Every behavior change needs tests or an explicit gap.

## Definition of done (slice)

- Spec or phase note updated  
- Tests prove the claim  
- Evidence path recorded on the claim  
- `pnpm verify` passes  
- No secret material  

## Virtuous-cycle invariant

Do not merge README fiction. Do not close gaps without proof. Do not scaffold the whole future desk before the next admitted slice.
